# موقع أكان العالمية للعقارات — نسخة ديمو

موقع عرض تجريبي لشركة أكان العالمية للعقارات (جدة): العقارات، مزاد «روح جدة»، المشاريع القادمة، وتسجيل الاهتمام.
مبني بـ Next.js 16 (App Router) و TypeScript و Tailwind CSS v4، عربي RTL بالكامل.

> **تنبيه:** هذه نسخة ديمو. طلبات الاهتمام لا تُرسل للشركة ولا تُحفظ، ولا يوجد دفع أو مزايدة داخل الموقع.
> المزايدة الفعلية تتم عبر منصة مباشر للمزادات كما في الكتيب.

## التشغيل محليًا

```bash
npm install
npm run dev        # http://localhost:3000
```

للنسخة الإنتاجية:

```bash
npm run build && npm run start
```

فحوصات: `npx tsc --noEmit` و `npm run lint`.

### ملاحظات دقة المحتوى

- يذكر الكتيب وقت البدء «04:00» والانتهاء «10:00» دون صباحًا/مساءً؛ تُعرض كما وردت.
- نص الموافقة في الكتيب يذكر «شركة أكان العقارية» بينما اسم الشركة في بقية الكتيب «اكان العالمية للعقارات»؛ النص منقول حرفيًا.
- الموقع الإلكتروني المطبوع في الكتيب `www.AKAN.com` معروض كنص فقط دون رابط.
- روابط «صور إضافية» (مجلدات Google Drive) منقولة من الكتيب لكل عقار. لا يوجد رابط خريطة في الكتيب.
- لا يوجد شعار معتمد؛ يُستخدم اسم «أكان» كعلامة نصية في `src/components/ui/Wordmark.tsx`.
  شعار الكتيب مستخرج للمرجع في `public/brand/` ويمكن اعتماده بتعديل هذا المكوّن فقط.
- قسم المشاريع تجريبي بلا أسماء أو أسعار أو مواعيد (`src/content/projects.ts`).

## بنية المشروع

```
src/
  content/        المحتوى منفصل عن الواجهة: properties.ts, auction.ts, company.ts, projects.ts
  lib/            format.ts, auction-status.ts, leads/ (zod schema + مستودع الطلبات)
  components/     layout/ ui/ properties/ auction/ interest/
  app/            الصفحات: / /properties /properties/[slug] /auction /interest /projects /about
  app/api/interest/route.ts   استقبال طلبات الاهتمام (تحقق + إيصال تجريبي)
public/
  images/         صور مستخرجة من الكتيب
  brochures/      كتيب المزاد الأصلي
  brand/          شعار الكتيب (غير مستخدم افتراضيًا)
```

### تحديث العقارات

أضف أو عدّل عنصرًا في `src/content/properties.ts` وضع الصورة في `public/images/properties/`.
التصفية (النوع/الحي) وصفحات العقارات تُبنى تلقائيًا من هذا الملف.

## الانتقال من الديمو إلى الإنتاج

1. **حفظ الطلبات:** أضف تنفيذًا لواجهة `LeadsRepository` في `src/lib/leads/repository.ts` متصلًا بقاعدة بيانات
   (مثل Postgres/Supabase) وبدّله في `getLeadsRepository()`. النموذج والمسار `/api/interest` يبقيان كما هما.
2. **الإشعارات:** أضف إرسال بريد/واتساب داخل `route.ts` بعد الحفظ.
3. **لوحة الإدارة:** صفحة محمية تقرأ `repository.list()`.
4. **التنبيهات التجريبية:** أزل `DemoBanner` ونصوص «نموذج تجريبي» في `InterestForm` و `robots: noindex` في `layout.tsx`.
